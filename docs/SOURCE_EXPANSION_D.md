## Skips and limits

- **Complete but no supported roles in this snapshot:** Zapier, Sentry, PostHog, Attio, Cockroach Labs, Tenable, Airtable, Udemy, Khan Academy, Course Hero, Pendo, FullStory, Dataiku, Imply, SingleStore, TransMarket Group, Morning Consult, DoubleVerify and NextRoll. Zero suitable roles is not a provider failure; these boards were omitted from this expansion rather than used to increase the employer count.
- **Unsupported or unavailable candidate endpoints:** Retool, Grammarly, DigitalOcean, Turo, Aurora, Coursera, Quizlet, Guild, Sisense, ThoughtSpot, DataRobot, Redis, Cogo Labs, Semrush, Sensor Tower and Integral Ad Science. Initial guessed endpoints returned HTTP 404. A readable official page or an old third-party index did not substitute for a complete valid current board. Alternate provider guesses were not declared verified.
- **Unsafe complete response:** Greenhouse `block` contained an unsafe posting URL, so the existing adapter rejected the whole snapshot. The URL validator was not weakened and no partial response was accepted.
- **Current feed responded, official identity not established to this pass’s standard:** Rubrik, Gong, Lucid Software, Astera Labs, Chime, SeatGeek, AppLovin, Taboola and Roku. Some official pages returned access-denied/challenge or HTTP 202 responses; others exposed only a generic/custom integration without exact board identity. Those responses were not bypassed or treated as verification. Their raw/supported counts were not added to this proposal.
- **Other career systems:** Railway’s visible careers content did not establish a supported board. Eventbrite careers redirected to Bending Spoons; no unverified or unsupported adapter was added. Clari careers redirected to Salesloft, which is added once. NerdWallet was left to group C to avoid duplicate research/import.
- **Geography quality observations shared with the root agent:** classifier `2026-10-26.2` still places some explicit foreign labels such as Moloco’s “Seoul, Korea” and a ClickHouse combination of Netherlands/Portugal/UK/Spain in needs-details. These records are not asserted to be US jobs. The root source audit should reprocess after any evidence-based geography correction; do not widen eligibility to keep the count.
- Handshake here is the company’s own employer board. No student authentication, third-party Handshake marketplace feed, LinkedIn scraping, application autofill or application submission was used.
- The source proposal preserves the existing Greenhouse full-response schema and `meta.total` check, Lever pagination and unique-ID checks, Ashby `isListed` filtering, safe URL validation, bounded request limits and complete-snapshot requirement. Failed or partial candidates cannot close listings.
- No Jobicy request, paid service, LLM API, authenticated ATS access, CAPTCHA bypass, headless browser scraping, privileged credential access or production write was performed. No canonical registry, shared source code or release-test report was changed by this research pass.
- Raw responses and complete snapshot caches are transient research files outside the repository in `/tmp/source-d-feeds`; the committed audit contains aggregate counts and identity evidence rather than payloads/descriptions. Source `usageReview` notes retain employer attribution and the requirement to disable unavailable-permission sources. Public endpoint access does not establish unrestricted republication rights or legal vetting.
