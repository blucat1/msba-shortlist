# Known limitations

The [site](https://msba-shortlist.pages.dev) and [repository](https://github.com/blucat1/msba-shortlist) use the owner's Cloudflare, Supabase and GitHub accounts. The completed protected release/import is recorded in [TEST_REPORT.md](TEST_REPORT.md): at 07:43 UTC on October 22, 2026 the default showed 15 listings across 8 companies, including 3 confirmed-zero requirements. Counts change with source availability and personal filters.

- **Partial market coverage.** The registry now contains 37 verified employer boards and one cross-employer remote feed, plus disabled candidates for ID.me’s university board (official linkage incomplete) and WisdomTree (source-use restriction unresolved). This is not the entire market. External Google/Indeed/LinkedIn searches are outbound links: their results are not imported, counted or verified. Public source totals include unrelated and experienced jobs. Coverage distinguishes raw source rows, retained supported records, default listings, companies and confirmed-zero listings.
- **Conservative graduate policy.** The default requires explicit graduate/entry-level evidence or an unconditional 0–1-year minimum. Six months and one year remain positive requirements. The separate **Zero years confirmed** view requires an explicit zero/no-experience requirement; graduate wording alone never supplies one. Senior, leadership, conditional experience and missing experience retain separate treatment. Narrowing discovery never deletes saved tracker records.
- **Eligibility is incomplete evidence.** Visible defaults are graduation **May 15, 2027**, earliest start **May 16, 2027**; custom profiles and explicit date opt-outs persist. Exact source dates, degree/field, GPA, US authorization and sponsorship are compared only when supported. Missing data, related-field acceptance, equivalent-experience paths, citizenship and unverified GPA scales remain unknown. Current authorization does not establish future sponsorship need. Known conflicts and passed verified deadlines leave the default view and can be explicitly reviewed. A matching check does not establish overall eligibility.
- **Rule extraction can miss requirements.** Unusual phrasing, unparsed requirements, truncated descriptions and source contradictions require reading the employer original. Plain text is bounded at 32,000 characters. Month/season windows use calendar bounds rather than invented event days; ambiguous alternatives can remain unknown. Dates without a source timezone do not establish a precise deadline cutoff.
- **Aggregator lag.** Jobicy's older CertiK entry-level listing conflicts with the current direct employer posting requiring 1–2 years. A dated, exact-identity/title review withholds that listing and links employer evidence without rewriting publisher text. This particular check is not independent employer verification of every aggregator listing, and it can age. The employer remains authoritative.
- **No validated hiring model.** Preference overlap is a hand-set sorting rule; eligibility filtering is separate. Scores are not displayed as probabilities or used to override known conflicts. The reviewed benchmark is an assistant-reviewed, purposively selected sample of bounded real source excerpts. It measures captured classification regressions and misses, not full-posting extraction recall, entire-market recall, interview odds or independent human validation. See [SUPPLY_REVIEW.md](SUPPLY_REVIEW.md) and the quality reports.
- **Grouped listings remain distinct.** For-you grouping uses matching recorded company/title/requirements and summary. Location/requisition variants retain independent source IDs and save/apply controls. Grouping does not prove identical unparsed qualifications or a unique number of hiring programs. All catalog exposes separate listings.
- **Google human pilot deferred.** The owner reported working Google sign-in and save/refresh; hosted API isolation/deletion checks were separately observed. Classmate testing is explicitly deferred by the owner. Two independent Google accounts, pending-request browser account switching, physical second-device persistence, audience access and usefulness/time measurements remain unexecuted. [PILOT_PROTOCOL.md](PILOT_PROTOCOL.md), [PILOT_RESULTS.md](PILOT_RESULTS.md) and the empty template prepare that later work without inventing results.
- **Validation environments differ.** Local unit/browser and PostgreSQL WASM checks, real disposable Supabase CI, hosted anonymous checks and human Google acceptance are distinct. The integration gate runs the actual four-provider ingestion entry point through real local Supabase SQL/Auth/repository/browser paths with external HTTP replaced by captured bounded data. It makes no live Jobicy polls. Its disposable local password accounts do not certify Google OAuth. The Mac requires Docker to execute that entire local gate; fixture-only mode is explicitly incomplete.
- **Publisher boundaries.** Jobicy covers a delayed rolling seven-day remote window, including country-unverified Anywhere results. Source publication time is not employer original posting time. Credit/canonical links and actual-company grouping survive saves/backups. Older IDs use publisher listing statuses; absence from the window never proves employer closure. Status unknown is withheld, explicit closed closes. The importer enforces a persisted one-hour attempt cooldown; credential-free audits/dry runs still need operator coordination.
- **Freshness and scale.** Refresh is twice daily, subject to GitHub delays/inactivity and free Supabase pauses. Stale at 36 hours; expired after 72 hours. Failed/partial/quarantined feeds cannot close old listings. Employer absence closure requires two complete snapshots at least 12 hours apart. A visible 5,000-record client recommendation cap, 24MB feed-response cap and bounded pagination remain scaling limits.
- **Compensation and dates.** Unknown currency, pay period, geography and base/total distinctions remain explicit. No hourly annualization or invented original dates. Greenhouse edits and Ashby last publication are separate timestamps. Demo dates are simulated and jobs fictional.
- **Owner controls do not guarantee zero cost.** Owner-only protected main merges, mandatory CI, exact-main environment secrets, owner-gated production reruns and disabled Cloudflare previews remain in place. No teammate invitations, billing access or paid services were added. Public visitors and future writers can still consume provider quotas; account-wide Cloudflare billing was not readable. No universal spending cap or control over copying public code is claimed. See [COLLABORATION.md](COLLABORATION.md).
- **Source use and privacy.** Public API access is not blanket republication permission or legal vetting; keep bounded text/attribution and disable sources requiring unavailable permission. No arbitrary-URL scraping, application autofill, Gmail, invitations, hidden analytics or automated submissions. An opened link is not Applied. Live private records use database owner policies; exports are private portable records, not automatic full-service disaster recovery. Provider backups may outlast deletion. Demo storage is browser-local and can be cleared.
