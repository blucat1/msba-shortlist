## Verification and usage boundaries

- Parsed every selected entry with sourceSchema and checked source/provider-board uniqueness against the existing registry. West Monroe intentionally shares an employer identity across two distinct boards.
- Existing Greenhouse meta.total, Lever pagination/unique IDs and Ashby listed-flag/full-schema policies validated selected complete snapshots. All 3,611 selected raw rows were re-normalized with classifier 2026-10-26.2. No snapshot closure/quarantine or URL safety policy was changed.
- Resolved current migrations from official evidence: Marqeta `marqeta-inc`, Spring Health's UUID Ashby board, NerdWallet Ashby, Navan `tripactions`, Rocket Money `truebill`, ShipBob `shipbobinc`, Addepar `addepar1`, and Optiver US `optiverus`. ShipBob itself currently contributes zero supported records, so remains deferred.
- Fixed official careers pages, their linked scripts/embedded ATS URLs, and exact posting title/ID/requisition cross-matches were inspected only to establish identity. Custom employer JSON endpoints were not used as catalog adapters. Upstart required one approved Greenhouse single-job metadata lookup to cross-check official requisition R-00471.
- The registry's narrowly validated Ashby identifier policy permits legitimate internal dots/spaces and keeps provider paths encoded. No slash, query, percent escape, traversal, credential or arbitrary-host permission was introduced by this work.
- Reviewed [Greenhouse public Job Board GET documentation](https://docs.greenhouse.io/job-board.html), [Lever public Postings API](https://github.com/lever/postings-api), and [Ashby public Job Postings API](https://developers.ashbyhq.com/docs/public-job-posting-api). Public technical access is not unrestricted republication permission. Discovery retains employer attribution and original links; disable sources if relevant employer/provider terms restrict the use or require unavailable permission.
- No Jobicy polling, paid service, LLM API, authenticated ATS, application submission, CAPTCHA/access-control bypass, arbitrary-URL job scraping, production write, commit or deployment. Final integration, application checks and actual production acceptance remain separate from this source review.
