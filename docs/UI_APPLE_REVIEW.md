# Material and navigation review — October 22, 2026

The owner requested a cohesive modern Apple-inspired interface. This review concerns the website's visual hierarchy and browser behavior; it does not claim native Apple Liquid Glass rendering, an Apple affiliation or complete accessibility conformance. The three primary destinations and existing job-search workflows remain the same.

Apple's [Materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials) reserves Liquid Glass for a distinct navigation/control layer, recommends using it sparingly and favors protective materials when text must remain legible over changing content. The implementation applies that principle to the header and floating mobile dock, while keeping job details, forms and tables readable. Apple's [Accessibility guidance](https://developer.apple.com/design/human-interface-guidelines/accessibility) also informs the reduced-motion and reduced-transparency checks.

## Review scope

Only fresh anonymous local-browser contexts and explicitly fictional, browser-local demo records are used before release. The review covers 320, 390, 768, 1024 and 1440 CSS pixels, scrolled content beneath the navigation, job details, preferences, manual entry, tracker rows, next steps and Insights. No real Google session, private cloud record, production import or job-feed request is part of this local review.

The existing workflow and geometry regressions remain in place. A new navigation regression checks label contrast composited over black and white underlying content, three primary links, touch targets, keyboard navigation, floating-dock insets, an opaque reduced-transparency alternative and reduced-motion modal presentation. These bounds supplement actual viewport screenshot inspection; they do not simulate every possible browser rendering effect.

## Independent visual assessment

The top navigation, segmented controls, restrained blue actions, neutral content surfaces and system typography now follow one visual language. Removing the fixed sidebar, promotional panels and decorative copy makes the interface read more like a focused application. Job titles, experience requirements, source context and individual actions retain clear priority. The compact profile and experience controls improve the route into listings without hiding their meaning; the mobile tracker still exposes its next action directly.

The glass is deliberately confined to the navigation and transient presentation layer. On a light canvas it is subtle; over scrolled content, the protective fill and blur preserve a distinct control layer. The 320px preferences header, close control and wrapped actions remain readable, and the floating mobile dock retains its insets and usable labels. No remaining visual blocker was identified in the reviewed standard/reduced viewport captures.

Physical-device behavior, native browser zoom, operating-system assistive technology, unsupported-backdrop-filter browsers, cross-browser acceptance and human preference/usefulness testing remain separate. The stylesheet provides a solid base before the supported-filter enhancement, but that unsupported-browser path has not been executed in a separate browser engine. Human testing remains explicitly deferred; no participants or outcomes are invented. These results describe local verification, not a claimed deployment.
